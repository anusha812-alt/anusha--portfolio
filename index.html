Smart Locker System using IoT

Team of 3, built with Python and ESP32

Purpose

Developed an IoT-based smart locker to protect valuable gadgets such as mobile phones and pen drives, providing users with enhanced security and privacy.

Authentication

Implemented dual-factor authentication combining fingerprint verification and keypad password entry. The locker opens only when the correct password is entered and remains closed otherwise.

Hardware and code

Wired the hardware using an ESP32, fingerprint sensor and keypad, and wrote the Python code that verifies the password.

Outcome

Delivered a working model designed with accuracy and ease of use in mind.
